API-Driven Semantic Vector Search (TF-IDF Similarity Engine)What it does: You fetch 50 articles or posts from an API (like Reddit or NewsAPI). The user enters a search query, and your program calculates exactly which articles match best based on word frequency—ranking them without any AI models.How it works mathematically: It uses TF-IDF (Term Frequency-Inverse Document Frequency) and Cosine Similarity. If a rare word appears multiple times in an article and also in the user's query, your code flags it as a strong match.
